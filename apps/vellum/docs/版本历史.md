# 版本历史

这里记录 Vellum 每个版本对你有什么变化。设置里的「关于」会显示当前版本，也可以在那里检查更新。

## 0.1.0

- 关于页可以查看版本、开源协议，以及 GitHub、问题反馈和邮箱。
- 可以检查并安装新版本。macOS 上正在用开发版运行时，不能在应用里安装更新，以免把正在调试的程序替换掉。

## 怎么发布新版本

在仓库根目录运行 `pnpm bump-vellum-version 0.1.1`。它会改应用版本号，并在结束时打印打标签的命令。然后在上面按同样的格式补上这一版的变化，标题用 `## 0.1.1`，下面用 `### What's new`。

提交这些改动之后，按脚本打印的命令打标签并推送，例如：

```bash
git tag vellum-v0.1.1
git push origin vellum-v0.1.1
```

GitHub Actions 会为 macOS、Windows 和 Linux 打安装包，并生成一份草稿 Release，名字是 `vellum-v0.1.1`。草稿不会覆盖 Inimark 的 Latest。确认安装包没问题后，在 GitHub 上发布这份草稿。

发布之后，应用里的「检查更新」才会看到这一版。更新清单放在固定的 `vellum-latest` 发布上，不要把那一份标成 Latest，否则会挡住 Inimark 自己的更新。

签名用的是仓库里已有的 `TAURI_SIGNING_PRIVATE_KEY`。没有这份密钥时，检查更新会失败。
