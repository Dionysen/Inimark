# @md/editor

Typora-style WYSIWYG Markdown editor core, integrated from [Albert-PZY/typora-web](https://github.com/Albert-PZY/typora-web).

## Attribution

This package is derived from **typora-web** by Yanzhen Yu (MIT License). See `UPSTREAM-LICENSE` for the original license text.

## Layout

- `src/` — editor implementation (ProseMirror + markdown-it)
- `specs/` — executable behavior specifications
- `tests/` — unit and spec-replay tests
