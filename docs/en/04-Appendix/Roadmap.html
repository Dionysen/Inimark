Roadmap

中文: 中文 · Feature Comparison · MOC-English Docs

An honest inventory from current code, not a dated commitment. Product priority is yours.

Already strong

  • Typora-style WYSIWYG + source + typewriter + focus (F8)

  • Rich Markdown: tables, tasks, callouts, TOC, front matter…

  • KaTeX · Mermaid

  • Libraries · tree · Quick Open · search · bookmarks · outline

  • [[wikilinks]] / ![[embeds]] · rewrite · graph

  • Theme packs · i18n · settings window · rebindable shortcuts

  • Publish SSG + local preview

  • Publish multilingual switcher (locales + translationKey)

  • Auto-update pipeline

Partial / exposed but unfinished

  • Cloud sync / collab / mobile

Publish extension ideas (when needed)

  1. Full-text site search
