# Relationship Graph

**中文:** [[关系图谱|中文]] · [[Wikilinks and Embeds]] · [[MOC-English Docs]]

The graph turns `[[wikilinks]]` into a space you can roam — nodes are notes, edges are links.

## Views

| Mode | Meaning | When to use |
| --- | --- | --- |
| Local | Active note + its outlinks and backlinks | Writing / reviewing one idea |
| Vault | Wider library graph | Finding clusters, orphans, hub notes |

Force layout spreads nodes to reduce overlap. Drag nodes, pan, and zoom as needed.

## Panel capabilities

| Action | Result |
| --- | --- |
| Click a node (without dragging) | Open that note in the editor |
| Fit | Frame the current graph in the viewport |
| Animate / timelapse | Playback-style layout motion (toolbar control) |
| Hover | Emphasize neighbors; dim the rest |
| Outlinks / Backlinks lists | Sidebar lists; click to open; unresolved outlinks marked |

A floating graph can open with complementary mode settings; Graph preferences sync across sidebar, floating panel, and **Settings → Graph**.

> [!TIP]
> Densify links in this help vault: connect [[MOC-English Docs]] to chapters, then open Graph — you’ll see the “docs site” as a shape in space.

### Reading recipe

1. Open a hub note (MOC).
2. Switch Graph to **local** — confirm children appear.
3. Flip to **vault** — notice clusters.
4. Click an unexpected neighbor — follow the thread in the editor.
5. Use backlinks on a concept note to find forgotten references.

## Settings (Graph)

**Settings → Graph** (and the in-panel gear) adjust visualization:

| Control | Role |
| --- | --- |
| Show arrows | Directed edges |
| Text / node / link size | Visual weight |
| Animate | Motion preference |
| Center / repulsion / link force & distance | Layout physics (0–100 style sliders) |

Use **Restore defaults** if a layout feels chaotic.

## Boundaries
