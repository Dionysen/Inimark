### Which callout?

| Kind | Use when |
| --- | --- |
| `NOTE` | Extra context that should not derail the story |
| `TIP` | A shortcut or practical habit |
| `IMPORTANT` | Something the reader must not miss |
| `WARNING` | Risk, incomplete feature, or easy mistake |
| `DANGER` | Data loss / irreversible foot-guns |

Aliases: `WARN` / `CAUTION` → warning. Full samples: [[Markdown Syntax#Callouts]].
