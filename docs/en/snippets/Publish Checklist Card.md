### Before you Publish

- [ ] Folders numbered for nav order (`00-`, `01-`, …)
- [ ] Home note set in `publish.config.json`
- [ ] `baseHref` matches the host (`/` or `/repo/`)
- [ ] Unique titles for clean `[[wikilinks]]`
- [ ] Preview once locally, then deploy `dist/`

See [[Publish a Site]].
