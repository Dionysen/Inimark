### Wikilinks in three minutes

1. Type `[[` → pick a note (or create one).
2. Alias: `[[Welcome|home]]`.
3. Heading: `[[Markdown Syntax#Tables]]`.
4. Embed a card: `![[Markdown Showcase Card]]`.
5. Open Graph → local neighbors, then vault-wide map.
