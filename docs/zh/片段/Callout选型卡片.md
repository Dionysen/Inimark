### 用哪种 Callout？

| 种类 | 何时用 |
| --- | --- |
| `NOTE` | 不打断主线的补充说明 |
| `TIP` | 快捷键或实用习惯 |
| `IMPORTANT` | 读者绝不能漏掉的事 |
| `WARNING` | 风险、未完成功能，或易踩坑 |
| `DANGER` | 数据丢失 / 不可逆踩雷 |

别名：`WARN` / `CAUTION` → warning。完整示例：[[Markdown语法#Callout]]。
