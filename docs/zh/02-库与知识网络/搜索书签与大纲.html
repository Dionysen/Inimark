搜索、书签与大纲

English: English · 界面导览 · 库与文件

侧栏三个「导航型」标签，和 关系图谱 互补。

Search · 库内搜索

打开 Search 标签，或按 Ctrl/⌘ + Shift + F。

能力说明
文件名子串匹配
内容笔记正文子串匹配
大小写不区分
运算符暂无——没有 path: / tag: 之类过滤
跳转打开文件，并可能在编辑器中揭示命中

结果会分批加载以保持流畅（大文件有上限）。若要在单篇里用正则，请用 文档内查找。

Search = 跨文件；Find（Ctrl/⌘ + F）= 当前文件。

Bookmarks · 书签

把常用笔记钉起来，并用 分组 整理。

当前模型以 文件 为主（文件夹书签已收敛掉）。

怎么用

  1. 在侧栏打开书签。

  2. 把当前笔记加进去（具体入口以你的版本界面为准）。

  3. 用分组区分「本周主线」「发布队列」「常青枢纽」。

  4. 点书签打开——比在树里翻更快。

典型用途：

  • 写作中的「本周主线」

  • 帮助库里的 MOC-中文文档

  • 发布前的校对清单笔记

  • 把 发布为网站 加书签

  • 把 Markdown语法 加书签

Outline · 大纲

根据当前笔记的 # 标题生成树，点击跳转。

适合：

  • 起草时长文结构导航

  • 不离开当前视图也能跳标题

大纲跟随当前笔记——换文件后树会刷新。标题编号清晰时，Publish 页面也更好读。

标签左右布局可在设置里调整 → 设置总览 · 界面导览。
