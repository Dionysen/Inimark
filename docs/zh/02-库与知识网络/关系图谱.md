# 关系图谱

**English:** [[Relationship Graph|English]] · [[双链与嵌入]] · [[MOC-中文文档]]

图谱把 `[[双链]]` 变成可漫游的空间——节点是笔记，边是链接。

## 视图

| 模式 | 含义 | 什么时候用 |
| --- | --- | --- |
| 局部 | 当前笔记 + 出链 + 回链 | 写 / 复盘某一个想法 |
| 库级 | 更广的库关系 | 找簇、找孤儿、找枢纽 |

力导向布局会散开节点，减少重叠。可拖节点、平移、缩放。

## 面板能力

| 操作 | 结果 |
| --- | --- |
| 点击节点（未拖动） | 在编辑器打开该笔记 |
| 在编辑区显示 | 用图谱覆盖编辑区（再点一次关闭） |
| 切换到其他文件 | 关闭编辑区图谱，回到编辑器 |
| 适配视图 | 把当前图框进视口 |
| 动画 / 时序 | 工具栏上的布局动画 |
| 悬停 | 当前节点与邻居平滑高亮，其余淡出 |
| 保存 / 改双链 | 图谱就地更新（保留布局），不做整图重排 |
| 出链 / 回链列表 | 侧栏列表；点击打开；未解析出链会标出 |

浮动图谱可与侧栏模式互补；图谱偏好在侧栏、浮动面板与 **设置 → Graph** 之间同步。

> [!TIP]
> 先把帮助库的双链写稠：从 [[MOC-中文文档]] 链到各章，再打开 Graph，会立刻看到「文档站」在空间中的形状。

### 阅读小流程

1. 打开一篇枢纽笔记（MOC）。
2. 图谱切到 **局部**——确认子笔记出现。
3. 再切 **库级**——观察簇。
4. 点一个意外邻居——在编辑器里顺着读。
5. 在概念笔记上看回链，找回被忘掉的引用。

## 设置（Graph）

**设置 → Graph**（以及面板内齿轮）可调：

| 控件 | 作用 |
| --- | --- |
| 显示箭头 | 有向边 |
| 文字淡出 | 缩小到一定程度后隐藏节点名；滑杆改变阈值。悬停仍会显示该节点名称。 |
| 节点 / 连线粗细 | 视觉权重 |
| 动画 | 是否偏好动效 |
| 向心力 / 斥力 / 连线力与距离 | 布局物理（约 0–100 滑杆） |
| 颜色分组 | 按查询给节点着色（见下文） |

布局乱了就用 **恢复默认**（同时会清空颜色分组）。

### 颜色分组

颜色分组按规则给匹配到的笔记上色。分组**自上而下**检查，**先命中先生效**；未命中任何分组的节点保持主题默认色。

图谱浮窗设置里的 **外观**、**力度**、**颜色分组** 可以展开 / 收拢（默认展开颜色分组）。**设置 → Graph** 页面与其它设置页一样，只用普通分组标题，不可收起。

每组包含：

- 启用开关
- 颜色
- **匹配方式**（路径、文件、标签、名称）
- 内容输入（会按所选方式提示可选项）

**匹配方式：**

| 类型 | 匹配范围 |
| --- | --- |
| 路径 | 库相对路径包含输入内容（不区分大小写） |
| 文件 | 文件名或笔记名包含输入内容 |
| 标签 | 带有该标签，或嵌套标签如 `inbox/later` |
| 名称 | 笔记名 / 文件名包含输入内容 |

例如：

- 路径 `docs/en` — 英文文档目录下的笔记
- 标签 `roadmap` — 带 roadmap 标签的笔记

每种规则单独加一组。用上移 / 下移调整优先级，把更具体的规则放在上面。

> [!NOTE]
> 按行、章节或笔记属性匹配尚未支持。

## 边界

| 有 | 无（目前） |
| --- | --- |
| 笔记关系图 | 标签图 |
| 出链 / 回链 | Canvas 白板编辑器 |
| 力导向 | Dataview 式查询 |
| 颜色分组（`path` / `file` / `tag`） | `line` / `section` / 属性着色 |

见 [[路线图]]、[[功能对照表]]。
