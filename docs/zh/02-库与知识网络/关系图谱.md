# 关系图谱

**English:** [[Relationship Graph|English]] · [[双链与嵌入]] · [[MOC-中文文档]]

图谱把 `[[双链]]` 变成可漫游的空间——节点是笔记，边是链接。

## 视图

| 模式 | 含义 | 什么时候用 |
| --- | --- | --- |
| 局部 | 当前笔记 + 出链 + 回链 | 写 / 复盘某一个想法 |
| 库级 | 更广的库关系 | 找簇、找孤儿、找枢纽 |

力导向布局会散开节点，减少重叠。可拖节点、平移、缩放。

## 面板能力

| 操作 | 结果 |
| --- | --- |
| 点击节点（未拖动） | 在编辑器打开该笔记 |
| 适配视图 | 把当前图框进视口 |
| 动画 / 时序 | 工具栏上的布局动画 |
| 悬停 | 强调邻居，其余变淡 |
| 出链 / 回链列表 | 侧栏列表；点击打开；未解析出链会标出 |

浮动图谱可与侧栏模式互补；图谱偏好在侧栏、浮动面板与 **设置 → Graph** 之间同步。

> [!TIP]
> 先把帮助库的双链写稠：从 [[MOC-中文文档]] 链到各章，再打开 Graph，会立刻看到「文档站」在空间中的形状。

### 阅读小流程

1. 打开一篇枢纽笔记（MOC）。
2. 图谱切到 **局部**——确认子笔记出现。
3. 再切 **库级**——观察簇。
4. 点一个意外邻居——在编辑器里顺着读。
5. 在概念笔记上看回链，找回被忘掉的引用。

## 设置（Graph）

**设置 → Graph**（以及面板内齿轮）可调：

| 控件 | 作用 |
| --- | --- |
| 显示箭头 | 有向边 |
| 文字 / 节点 / 连线粗细 | 视觉权重 |
| 动画 | 是否偏好动效 |
| 向心力 / 斥力 / 连线力与距离 | 布局物理（约 0–100 滑杆） |

布局乱了就用 **恢复默认**。

## 边界

| 有 | 无（目前） |
| --- | --- |
| 笔记关系图 | 标签图 |
| 出链 / 回链 | Canvas 白板编辑器 |
| 力导向 | Dataview 式查询 |
