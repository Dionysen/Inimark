# 库与文件

**English:** [[Libraries and Files|English]] · [[双链与嵌入]] · [[MOC-中文文档]]

## 什么是库（Library）

库 ≈ Obsidian 的 Vault：一个装着 Markdown（以及磁盘上资源）的 **本地文件夹**。

Inimark 支持 **多库**。可在 **设置 → Libraries** 管理，也可以再打开 / 拖入别的文件夹。

> [!IMPORTANT]
> 本帮助站的源就是仓库里的 `docs/`——把它当作一个库打开即可。

### 创建或切换

1. **打开文件夹**（快捷键常为 `Ctrl/⌘ + Shift + O`）或把文件夹拖进应用。
2. 该文件夹会进入库列表；上次打开的库会被记住。
3. 之后可在壳层库列表或 设置 → Libraries 切换。

每个库有自己的会话（当前文件、展开目录、光标 / 滚动 / 源码模式），存在 `.inimark/`——见 [[数据目录]]。

## 文件树里会出现什么

| 会显示 | 不会作为行显示 |
| --- | --- |
| `.md` / `.markdown` / `.mdown` 笔记 | 图片等其它二进制文件 |
| 你创建的文件夹 | 以 `.` 开头的文件 / 文件夹 |

图片仍可嵌入——在磁盘上整理资源，详见 [[图片与附件]]。

## 文件树（Files）

| 操作 | 说明 |
| --- | --- |
| 新建 | 笔记 / 文件夹 |
| 重命名 | 可能触发改链（`F2`） |
| 删除 | 需确认（`Delete`） |
| 移动 | 拖拽或剪切粘贴 |
| 定位 | 在树中揭示当前文件 |
| 排序 | 按名称等规则 |

支持 **拖拽** 整理。文件树聚焦时，剪切 / 复制 / 粘贴快捷键作用于资源管理器操作。

## 快速打开（Quick Open）

模糊匹配文件名 + 最近打开——日常跳转主力。

常绑定在「打开」快捷键上（可在 Shortcuts 重绑）→ [[查找替换与快捷键]]。

## 导航历史

标题栏 **后退 / 前进** 在浏览过的笔记间移动，类似浏览器——见 [[界面导览]]。

## 会话记忆

每个库会记住视图状态（光标、滚动、源码模式、展开目录等），例如 `.inimark/session.json`。

## 重命名与移动

当被双链引用的笔记被重命名或移动时，Inimark 可按 **设置 → Editor**（移动时更新链接）改写其它文件里的 `[[链接]]`：

| 策略 | 行为 |
| --- | --- |
| ask | 每次询问（稳妥默认） |
| always | 总是改写（大规模整理） |
| never | 从不改写（完全手动） |

细节见 [[双链与嵌入#重命名与改链]]。

文件树重命名 / 移动时：

1. 若影响双链 → 按策略改写（`ask` / `always` / `never`）
2. 否则 → 仅更新路径
3. 随后刷新 link-index

### 多库怎么分比较顺手

| 库 | 例子 |
| --- | --- |
| 工作 | 项目说明、会议纪要 |
| 个人 | 日记、读书笔记 |
| 发布 | 有意要上线的库（例如本 `docs/`） |

把 `publish.config.json` 放在你真正要构建的那个库里。
