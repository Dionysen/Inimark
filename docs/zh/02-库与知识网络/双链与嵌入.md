# 双链与嵌入

**English:** [[Wikilinks and Embeds|English]] · [[关系图谱]] · [[库与文件]]

双链是 Inimark「思维功能」的核心，语法对齐 Obsidian 习惯。

![[双链三分钟卡片]]

## 基础链接

```markdown
[[欢迎]]
[[欢迎|自定义文案]]
[[Markdown语法#表格]]
[[Markdown语法#Callout|跳到 Callout]]
```

实况：

- 普通：[[欢迎]]
- 别名：[[MOC-中文文档|打开中文目录]]
- 标题：[[Markdown语法#Callout]]
- 标题 + 别名（写在正文/列表里）：`[[笔记#标题|显示文案]]` 可用
- 跨语言：[[Welcome|English Welcome]]

> [!TIP]
> 输入 `[[` 会触发自动补全（`![[` 嵌入场景不会）。笔记按 **去扩展名的路径** 索引，也支持按 **文件名** 解析（重名时偏好更浅路径）。标题锚点请写 **与目标标题完全一致** 的全文（含括号补充），例如 `[[日常场景#长文写作（文章、报告、章节）]]`。

> [!WARNING]
> **不要**在 Markdown **表格单元格**里写带 `|` 别名的双链（`[[笔记|别名]]` / `[[笔记#标题|别名]]`）。别名的 `|` 会和表格列分隔符冲突，链接会被拦腰截断，看起来像「坏掉」。表格里用不带别名的链接，或把带别名的链接写在普通段落 / 列表里。

### 自动补全习惯

| 输入 | 行为 |
| --- | --- |
| 空的 `[[` | 最近笔记（若干条）+ 更广列表 |
| 输入关键字 | 过滤候选（有上限） |
| ↑ ↓ / Enter / Tab | 选择并确认 |
| 无匹配时按 Enter | 可以新建笔记 |
| `|` 或 `#` | 结束名称查询——后面接别名或标题 |

未解析链接会用更醒目 / 虚线样式标出。修正标题、创建笔记，或删掉坏链即可。

## 嵌入

### 笔记嵌入

```markdown
![[语法速览卡片]]
```

效果：

![[语法速览卡片]]

适合复用片段、MOC、在长文里引用定义卡。

### 图片嵌入

```markdown
![[photo.png]]
```

常见光栅 / 矢量类型在库内可解析时会渲染为图片嵌入。优先用库内相对资源——见 [[图片与附件]]。

> [!WARNING]
> 避免 **循环嵌入**（A 嵌 B、B 嵌 A），阅读与发布都会变难。

## 轻量知识库写法

1. 一篇 **枢纽 / MOC**，正文几乎都是子笔记的 `[[链接]]`。
2. 概念笔记写短一点，外链出去而不是复制粘贴。
3. 长文需要同一段定义时，嵌入「定义卡」。
4. 每周用 [[关系图谱]] 局部模式扫一眼邻居。

本库的 [[MOC-中文文档]] 就是活例子。

## 出链与反向链接

| 概念 | 含义 |
| --- | --- |
| Outlinks | 当前笔记指向哪些笔记 |
| Backlinks | 哪些笔记指向当前笔记 |

列表在 [[关系图谱]] 面板；未解析出链会标出来。图谱可视化同一份索引。

## 索引

库内维护链接索引（缓存于 `.inimark/link-index.json`）：

1. 从 Markdown 解析 `[[…]]`
2. 构建 / 刷新 `link-index`
3. 供给自动补全、Graph、以及 Publish 的 href 解析

见 [[数据目录]]。

## 重命名与改链

在文件树中 **重命名 / 移动** 时，Inimark 可改写其它文件里的 `[[链接]]`（含 `#标题` 与 `|别名` 后缀）：

| 策略 | 场景 |
| --- | --- |
| ask | 默认稳妥 |
| always | 大规模整理结构 |
| never | 完全手动控制 |

在设置 → Editor（移动时更新链接）配置；操作入口见 [[库与文件]]。

## 尚未覆盖的链接能力

对照 Obsidian，下列能力 **当前没有或仅部分**：

- [ ] 块引用 `[[note#^block-id]]`（完整体系）
- [ ] 标签面板 / `#tag` 一等公民解析（样式有，解析弱）
- [ ] 悬停预览的完整产品化文档（编辑器内有预览能力，以实机为准）

诚实清单见 [[路线图]] 与 [[功能对照表]]。
