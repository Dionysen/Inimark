# 双链与嵌入


**English:** [[Wikilinks and Embeds|English]] · [[关系图谱]] · [[库与文件]]

双链是 Inimark「思维功能」的核心，语法对齐 Obsidian 习惯。

## 基础链接

```markdown
[[欢迎]]
[[欢迎|回到首页文案]]
[[Markdown语法#表格]]
```

实况：

- 普通：[[欢迎]]
- 别名：[[MOC-中文文档|打开中文目录]]
- 标题：[[Markdown语法#Callout 提示块]]
- 跨语言：[[Welcome|English Welcome]]

> [!TIP]
> 输入 `[[` 会触发自动补全。笔记名按 **路径去扩展名** 索引，也支持按 **文件名** 解析（重名时偏好更浅路径）。

## 嵌入

```markdown
![[语法速览卡片]]
```

效果：

![[语法速览卡片]]

嵌入适合：复用片段、MOC 聚合、在长文中引用定义卡。

> [!WARNING]
> 避免 **循环嵌入**（A 嵌 B、B 嵌 A），阅读与发布都会变难。

## 出链与反向链接

| 概念 | 含义 |
| --- | --- |
| Outlinks | 当前笔记指向哪些笔记 |
| Backlinks | 哪些笔记指向当前笔记 |

在 [[关系图谱]] 面板的列表区可以查看；图谱把同一份索引可视化。

## 索引

库内维护链接索引（缓存于 `.inimark/link-index.json`）：

```mermaid
flowchart LR
  MD[Markdown 文件] --> Parse[解析 [[…]]]
  Parse --> Idx[link-index]
  Idx --> AC[自动补全]
  Idx --> G[Graph]
  Idx --> Pub[Publish 解析 href]
```

见 [[数据目录]]。

## 重命名与改链

当你在文件树中 **重命名 / 移动** 笔记，Inimark 可按设置改写其它文件里的 `[[链接]]`：

| 策略 | 场景 |
| --- | --- |
| ask | 默认稳妥 |
| always | 大规模整理结构 |
| never | 你想完全手动控制 |

相关设置在 Libraries / 链接更新相关选项；操作入口在 [[库与文件]]。

## 尚未覆盖的链接能力

对照 Obsidian，下列能力 **当前没有或仅部分**：

- [ ] 块引用 `[[note#^block-id]]`（完整体系）
- [ ] 标签面板 / `#tag` 一等公民解析（样式有，解析弱）
- [ ] 悬停预览的完整产品化文档（编辑器内有预览能力，以实机为准）

诚实清单见 [[路线图]] 与 [[功能对照表]]。
