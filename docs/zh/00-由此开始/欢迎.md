# 欢迎使用 Inimark

[toc]

**English:** [[Welcome|English]] · 目录：[[MOC-中文文档]]

> [!IMPORTANT]
> Inimark 的目标不是「再做一个 Obsidian」，也不是「再做一个 Typora」，而是：
>
> **编辑体验尽量超越 Typora**，同时具备 **Obsidian 式的思维与知识网络**，并加上自己的能力。

<!--more-->

## 一句话定位

| 维度  | Inimark 怎么做                               |
| --- | ----------------------------------------- |
| 编辑  | Typora 风格 **所见即所得**（无分屏预览）                |
| 知识  | 本地 **库（Libraries）** + `[[双链]]` + [[关系图谱]] |
| 输出  | 同一份笔记 → **静态网站**                          |

$$
\text{Inimark} \approx \underbrace{\text{WYSIWYG}}_{\text{Typora}} + \underbrace{\text{Vault + Graph}}_{\text{Obsidian}} + \underbrace{\text{SSG}}_{\text{Publish}}
$$

### 三分钟路径

1. [[安装与启动]] — 跑起来
2. [[界面导览]] — 认界面
3. [[Markdown语法]] — 感受编辑
4. [[双链与嵌入]] — 把笔记连起来
5. [[发布为网站]] — 导出本帮助库

> [!TIP]
> 本 `docs/` 目录就是一份可发布的帮助库。用 Inimark **打开此文件夹为库**，即可边读边改，再 Publish。

## 设计原则（给好奇的人）

- **单一编辑表面**：不靠左右分屏「预览」，而是让源码标记在需要时出现。
- **本地优先**：库在磁盘上；元数据在 `.inimark/`（见 [[数据目录]]）。
- **少而清晰**：侧栏标签可配，但不引入插件市场（至少目前如此，见 [[路线图]]）。
