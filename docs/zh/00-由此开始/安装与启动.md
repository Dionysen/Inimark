# 安装与启动

**English:** [[Install Inimark|English]] · 返回 [[欢迎]] · [[MOC-中文文档]]

> [!NOTE]
> Inimark 是 **Tauri 2** 桌面应用：Vite + TypeScript 界面，编辑器核心在 `@inimark/editor`，原生 I/O 在 Rust。

## 从 GitHub Releases 安装（推荐）

到官方发布页下载安装包：

[https://github.com/Dionysen/Inimark/releases](https://github.com/Dionysen/Inimark/releases)

按平台选资源：

| 平台 | 推荐资源 |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` 或 `.app.tar.gz` |
| macOS（Intel） | `.dmg` 或 `.app.tar.gz` |
| Windows | `.msi` 或 `.exe`（NSIS） |
| Linux | `.AppImage` / `.deb` / `.rpm` |

装好后启动 Inimark，打开本地库。应用内更新会读取同一发布页上的 `latest.json`。

> [!TIP]
> 优先用 **Latest** 版本。若系统拦截未签名下载，请在隐私 / 安全设置里允许。

### 第一次启动（建议步骤）

1. 打开 Inimark。
2. **打开文件夹**（或把文件夹拖进去）以创建 / 选择库 — 这份帮助库就是仓库的 `docs/` 目录。
3. 可选：在 **设置 → 外观 → 语言** 里选 `en` / `zh-CN` / 跟随系统。
4. 浏览 [[界面导览]]，再写一篇随便的笔记感受 WYSIWYG。

### 系统拦截应用时

| 平台 | 常见处理 |
| --- | --- |
| macOS | **隐私与安全性** → 允许 / 仍要打开；或右键 → 打开一次 |
| Windows | SmartScreen → 更多信息 → 仍要运行（仅在你信任该 GitHub 资源时） |
| Linux | 若桌面要求，给 AppImage 可执行权限（`chmod +x`） |

更多：[[常见问题]]。

## 打开这份帮助库

1. 启动 Inimark
2. **打开文件夹**，选中仓库的 `docs/` 目录
3. 从 [[欢迎]] 或 [[MOC-中文文档]] 开始
4. 准备好后，打开设置 → **发布**（见 [[发布为网站]]）

### 检查清单

- [ ] 已从 Releases 安装并能启动
- [ ] 已把 `docs/` 加为库
- [ ] （可选）发布预览能打开

## 更新

Inimark 可从 GitHub Releases 检查更新（见 **设置 → 关于**）。除非在排查特定构建，否则建议停留在 Latest。

各版本的下载入口与更新说明见 [[版本历史]]。

## 从源码构建（贡献者）

开发构建需要本地工具链：

| 依赖 | 建议 |
| --- | --- |
| Node.js | 20+ |
| pnpm | 10+ |
| Rust | stable（`pnpm tauri dev` 需要） |

```bash
pnpm install

# 编辑器单元 + 规格测试
pnpm test:editor

# 桌面集成测试
pnpm test:desktop

# 浏览器里跑编辑器
pnpm dev

# Tauri 桌面
pnpm tauri dev
```

> [!WARNING]
> 第一次 `pnpm tauri dev` 会编译 Rust crates，可能较久。请按系统安装 [Tauri 前置依赖](https://v2.tauri.app/start/prerequisites/)。

## 架构示意

- **`apps/desktop`** — 外壳、侧栏、设置、发布 UI
- **`packages/editor`** — ProseMirror 所见即所得（书写面）
- **`site-render` + `inimark-ssg`** — 构建 HTML，再预览或写出 `dist/`

桌面外壳驱动编辑器；Publish 经 site-render 进入 SSG。

另见 [[功能对照表]] 与 [[数据目录]]。
