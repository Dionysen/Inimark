界面导览

English: English · MOC-中文文档

主窗口大致是「左右侧栏夹着中间编辑区」：标题栏在顶，状态栏在底，中间书写；两侧可挂文件树、大纲等标签（可收起）。

位置常见内容
顶栏后退 / 前进、窗口控制、更多菜单
左侧栏文件、搜索、书签、大纲、图谱（可配置）
中间编辑器：所见即所得 或 源码
右侧栏同上，标签左右可互换
底栏字数、打字机等状态

标题栏

区域作用
后退 / 前进在已打开笔记间的 库与文件 › 导航历史
窗口控制最小化 / 最大化 / 关闭（macOS 为红绿灯）
更多菜单沉浸式外观：自动隐藏标题栏 / 状态栏，以及相关专注选项

想少打扰地写字时，可自动隐藏标题栏和状态栏，界面更接近「一张纸」。见 主题与外观。

双侧栏

左侧与右侧的 标签可配置（文件 / 搜索 / 书签 / 大纲 / 图谱）。

标签一句话深入阅读
文件库的文件树库与文件
搜索按名称 + 内容搜索搜索书签与大纲
书签书签与分组搜索书签与大纲
大纲当前笔记的标题树搜索书签与大纲
图谱图谱外加出链 / 入链关系图谱

如何安排标签

  1. 打开 设置 → 外观。

  2. 把每个标签分配到 左 或 右 侧栏列表。

  3. 拖侧栏边缘改宽度；需要更宽书写区时再收起。

两侧栏都可以收起 — 中间编辑区占满。用侧栏快捷键切换显示（默认 Ctrl/⌘ + B，可改绑）。

编辑器区域

中间是 @inimark/editor：

  • 默认 所见即所得（WYSIWYG）

  • Ctrl/⌘ + / 切换 源码模式

  • 打字机（F9 / 状态栏）与 专注（F8 / 设置 / 更多 → 沉浸）

右键菜单可插入格式、链接、Callout — 见 Markdown语法。

状态栏

常见项：

  • 字数 / 字符数

  • 打字机开关

  • 滚到顶部 / 底部

  • 其他编辑状态（取决于配置）

设置窗口

设置在 独立窗口 打开，并支持搜索。见 设置总览：
