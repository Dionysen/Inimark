# 界面导览

**English:** [[Interface Tour|English]] · [[MOC-中文文档]]

可以把主窗口想成三栏：

```text
┌──────────┬─────────────────────┬──────────┐
│ 左侧     │     编辑器          │  右侧    │
│ 文件…    │  WYSIWYG / 源码     │ 大纲…    │
└──────────┴─────────────────────┴──────────┘
               状态栏 / 标题栏
```

## 标题栏

| 区域 | 作用 |
| --- | --- |
| 后退 / 前进 | 在已打开笔记间的 [[库与文件#导航历史|导航历史]] |
| 窗口控制 | 最小化 / 最大化 / 关闭（macOS 为红绿灯） |
| 更多菜单 | 沉浸式外观：自动隐藏标题栏 / 状态栏，以及相关专注选项 |

> [!TIP]
> 想少打扰地写字时，可自动隐藏标题栏和状态栏，界面更接近「一张纸」。见 [[主题与外观]]。

## 双侧栏

左侧与右侧的 **标签可配置**（文件 / 搜索 / 书签 / 大纲 / 图谱）。

| 标签 | 一句话 | 深入阅读 |
| --- | --- | --- |
| 文件 | 库的文件树 | [[库与文件]] |
| 搜索 | 按名称 + 内容搜索 | [[搜索书签与大纲]] |
| 书签 | 书签与分组 | [[搜索书签与大纲]] |
| 大纲 | 当前笔记的标题树 | [[搜索书签与大纲]] |
| 图谱 | 图谱外加出链 / 入链 | [[关系图谱]] |

### 如何安排标签

1. 打开 **设置 → 外观**。
2. 把每个标签分配到 **左** 或 **右** 侧栏列表。
3. 拖侧栏边缘改宽度；需要更宽书写区时再收起。

两侧栏都可以收起 — 中间编辑区占满。用侧栏快捷键切换显示（默认 `Ctrl/⌘ + B`，可改绑）。

## 编辑器区域

中间是 `@inimark/editor`：

- 默认 [[编辑模式#所见即所得|所见即所得（WYSIWYG）]]
- `Ctrl/⌘ + /` 切换 [[编辑模式#源码模式|源码模式]]
- [[编辑模式#打字机模式|打字机]]（`F9` / 状态栏）与 [[编辑模式#专注模式|专注]]（`F8`）

右键菜单可插入格式、链接、Callout — 见 [[Markdown语法]]。

## 状态栏

常见项：

- 字数 / 字符数
- 打字机开关
- 滚到顶部 / 底部
- 其他编辑状态（取决于配置）
