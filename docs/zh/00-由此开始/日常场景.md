# 日常场景

**English:** [[Everyday Workflows|English]] · [[欢迎]] · [[MOC-中文文档]]

功能页告诉你 Inimark *能做什么*。这一页讲 *大家怎么用* — 挑一条贴近你这一周的路径即可。

> [!TIP]
> 把这份 `docs/` 当作库打开，在一篇用完即丢的笔记上试每个流程。肌肉记忆比截图管用。

## 长文写作（文章、报告、章节）

**目标：** 在一块书写面上保持心流，结构随时一键可达。

1. 从 [[编辑模式#所见即所得|WYSIWYG]] 开始。用 `Ctrl/⌘ + 1…6` 写标题。
2. 右侧保留 [[搜索书签与大纲#Outline · 大纲|大纲]]，不用盲滚就能跳段落。
3. 长时写作打开 [[编辑模式#打字机模式|打字机]]（`F9` 或状态栏）；周围块太吵时用 [[编辑模式#专注模式|专注]]（`F8`、设置或 更多 → 沉浸）。
4. 某段需要「大手术」（粘贴来的 HTML、坏掉的表格）时，用 `Ctrl/⌘ + /` 切到 [[编辑模式#源码模式|源码]]，修好再切回。
5. 整周反复回来写的话，把草稿钉在 [[搜索书签与大纲#Bookmarks · 书签|书签]]。

**好习惯**

- 宁可多几个短小节，也不要一整堵墙文字 — 大纲和发布都会更清晰。
- 旁白用 Callout，主线保持干净 — 见 [[Markdown语法#Callout]]。
- 自动保存 + 保存时格式化（设置 → 编辑器）让文件对 [[发布为网站]] 更友好。

## 个人知识库（用链接长出来的笔记）

**目标：** 不靠插件市场，也能长出本地想法网络。

1. 在 [[库与文件]] 下按生活领域或项目建文件夹。
2. 写一篇索引笔记（迷你 MOC），里面主要是指向子笔记的 `[[双链]]` — 这份帮助库的 [[MOC-中文文档]] 就是范例。
3. 写作时输入 `[[`，从自动补全选笔记；句子需要不同措辞时用别名：`[[笔记|口语标签]]`。
4. 用 `![[…]]` 嵌入可复用的定义卡片，别复制粘贴 — 见 [[双链与嵌入]]。
5. 打开 [[关系图谱]] 的 **局部** 模式看当前笔记邻居；想看整张图时切到 **库**。

**好习惯**

- 标题尽量唯一，减少歧义链接。
- 重命名后，链接改写策略先保持 **询问**，习惯后再对大整理用 **始终**（[[双链与嵌入#重命名与改链]]）。
- 把「枢纽」笔记放进书签，别只靠快速打开。

## 技术笔记（代码、图表、API）

**目标：** 代码和图表可读，正文仍保持 Typora 般顺滑。

1. 代码片段用围栏代码块；语言标签决定高亮。
2. 架构 / 时序 / 状态 → 用 `mermaid` 围栏 — 食谱在 [[数学公式与图表]]。
3. 公式用 `$…$` / `$$…$$`（KaTeX）。改长对齐式时优先源码模式。
4. 用双链关联相关 RFC 或设计文档，图谱会显示「这个决定依赖…」。

**好习惯**

- 一个想法一张图；把 Mermaid 源码留在笔记里，以后还能改。
- 剪贴板 HTML 搞乱缩进时，用纯文本粘贴（`Ctrl/⌘ + Shift + V`）。

## 发布手册或课程笔记

**目标：** 同一座库变成静态站点。

1. 文件夹编号（`00-`、`01-`…），导航顺序一目了然。
2. 首页笔记清晰，标题唯一。
3. 在设置 → 发布里预览，再部署 `dist/` — 完整步骤见 [[发布为网站]]。
4. 需要中英双语时，沿用本库的 `locales` + `translationKey` 约定。

## 阅读笔记与文献

**目标：** 快速记下引文，之后再连起来。

1. 每篇论文 / 书 / 文章一篇笔记。
2. 引用用引用块；你的评论用 Callout `NOTE`。
3. 把已有的人物、概念、项目用双链连上。
4. 记得一句话却忘了文件名时，用库搜索（`Ctrl/⌘ + Shift + F`）。
