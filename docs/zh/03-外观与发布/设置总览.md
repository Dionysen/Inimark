## Editor 选项（白话）

| 选项 | 效果 | 什么时候适合默认开着 |
| --- | --- | --- |
| 打字机 | 光标行靠近垂直居中 | 长写作 |
| 专注 | 淡化光标以外的块 | 笔记较密、想少一点视觉干扰 |
| 首行缩进 | 顶层段落首行缩进约两个汉字宽（仅显示，不进 Markdown） | 中文正文 / 正式文稿 |
| 自动隐藏标题栏 / 状态栏 | 更多画布、更少 chrome | 专注起草 |
| 编辑器 / 代码字体与字号 | 阅读舒适度 | 在意排版手感 |
| 编辑器宽度 | 限制行长 | 散文型笔记 |
| 自动保存 + 延迟 | 少按保存也不慌 | 日常使用 |
| 移动时更新链接 | `ask` / `always` / `never` | 先从 `ask` 开始 |
| 双链预览 | 按住 Ctrl/⌘ 悬停，或直接悬停 | 预览太吵时可保持「按住修饰键」 |
| 保存时格式化 | CJK 空格、裁剪空白、文件末换行、压缩空行 | 共享 / 要发布的库 |

专注与打字机也有快捷键（`F8` / `F9`）；打字机还有状态栏入口。沉浸 chrome 与专注都在 **更多 → 沉浸编辑**。

## Appearance 选项

| 选项 | 效果 |
| --- | --- |
| Locale | 应用 UI：`en` / `zh-CN` / 跟随系统 |
| 菜单密度 | 紧凑 / 常规 / 宽松 |
| 自动隐藏库栏 | 多一点纵向空间 |
| 文件树图标 | Files 里的视觉提示 |
| 左右侧栏标签 | 比如大纲贴编辑器、图谱放左边 |
