主题与外观

English: English · 发布为网站 · 界面导览

外观模式

模式说明
Light浅色
Dark深色
System跟随操作系统

内置含 Light / Grey / Slate / Claude Code / Mint / Purple / Hermes / Ocean / Dark Modern / Cursor / Dracula；也可导入 自定义主题包（.inimark-theme.json）。名称均为英文。

相关 chrome 选项在 设置 → Appearance：界面字体、菜单密度、自动隐藏库栏、文件树图标，以及 左右侧栏标签分配。

主题包能覆盖什么

  • 应用 + 编辑器配色（CSS 变量）

  • 代码高亮主题（--hljs-* 一类变量）

  • 毛玻璃等材质感（视主题与设置）

  • 取色器辅助自定义主题

内置代码主题

在 设置 → Theme 里选择代码主题（与应用外观主题相互独立）。明暗成对的包括：

LightDark
GitHub LightGitHub Dark
Atom One LightAtom One Dark
VS Code LightVS Code Dark
Solarized LightSolarized Dark
Cursor LightCursor Dark
Rider LightRider Dark

另有偏暗色经典：Nord、Monokai、Dracula。

可打开 代码与语法高亮，一边切换主题一边看高亮效果。

导出喜欢的主题，换机器再导入——外观是可迁移的资产。

主题包形态（给作者）

.inimark-theme.json 大致如下：

{
  "format": "inimark-theme-pack",
  "version": 2,
  "name": "我的主题包",
  "exportedAt": "2026-01-01T00:00:00.000Z",
  "themes": {
    "app": [{ "name": "My App", "variables": { "--bg": "…" } }],
    "code": [{ "name": "My Code", "variables": { "--hljs-bg": "…" } }]
  }
}

只有自定义主题参与选择性导入 / 导出。除非你清楚要改哪些变量，否则优先用应用内 Theme 界面，少手写包。

沉浸式 chrome

结合 界面导览：

  • 自动隐藏标题栏

  • 自动隐藏状态栏

  • 按需折叠侧栏

目标：编辑面最大化——接近 Typora 的专注感，同时保留 Obsidian 式侧栏。可与专注（F8）、打字机（F9）一起用——见 编辑模式。

字体与缩放

  • 编辑器 / 代码字体与字号： 设置 → Editor

  • 界面字体： 设置 → Appearance

  • 快速缩放：编辑区 Ctrl/⌘ + 滚轮——见 查找替换与快捷键

与 Publish 的关系

静态站点可以复用应用主题体系。在 publish.config.json 里常见：

  • defaultTheme — 初始主题 id

  • lightTheme / darkTheme — 站点界面切换用的一对

  • lightCodeTheme / darkCodeTheme — 代码块语法高亮用的一对

在 设置 → 发布 中，这些主题选项单独放在 主题 分组里（与站点名、输出目录、首页笔记分开）。

{
  "siteName": "Inimark Docs",
  "defaultTheme": "light",
  "lightTheme": "light",
  "darkTheme": "dark-modern",
  "lightCodeTheme": "github-light",
  "darkCodeTheme": "github-dark",
  "baseHref": "/",
  "out": "dist"
}
