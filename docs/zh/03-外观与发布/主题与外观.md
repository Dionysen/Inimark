# 主题与外观


**English:** [[Themes and Appearance|English]] · [[发布为网站]] · [[界面导览]]

## 外观模式

| 模式 | 说明 |
| --- | --- |
| Light | 浅色 |
| Dark | 深色 |
| System | 跟随操作系统 |

内置主题包括 Light / Grey / Dark 等；还可导入 **自定义主题包**（`.inimark-theme.json`）。

## 主题包能做什么

- 应用 UI 与编辑器配色
- 代码高亮主题
- 毛玻璃等材质感选项（视主题与设置）
- 取色器辅助自定义

> [!TIP]
> 导出你喜欢的主题，放到另一台机器再导入——主题是可迁移的「外观资产」。

## 沉浸式 chrome

结合 [[界面导览]]：

- 自动隐藏标题栏
- 自动隐藏状态栏
- 双栏按需折叠

目标：**编辑面最大化**，接近 Typora 的专注感，同时保留 Obsidian 式侧栏。

## 与 Publish 的关系

静态站点可以沿用应用主题体系（默认主题等写入 `publish.config.json`）。

本库配置示例字段：

```json
{
  "siteName": "Inimark Docs",
  "defaultTheme": "light",
  "baseHref": "/",
  "out": "dist",
  "home": "README.md"
}
```

完整流程见 [[发布为网站]]。

## 字体与缩放

编辑区可用滚轮缩放（[[查找替换与快捷键]]）；系统字体相关能力由桌面壳提供。
