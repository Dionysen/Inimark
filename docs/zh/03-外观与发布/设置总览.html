Editor 选项（白话）

选项效果什么时候适合默认开着
打字机光标行靠近垂直居中长写作
专注淡化光标以外的块笔记较密、想少一点视觉干扰
首行缩进顶层段落首行缩进约两个汉字宽（仅显示，不进 Markdown）中文正文 / 正式文稿
自动隐藏标题栏 / 状态栏更多画布、更少 chrome专注起草
编辑器 / 代码字体与字号阅读舒适度在意排版手感
编辑器宽度限制行长散文型笔记
自动保存 + 延迟少按保存也不慌日常使用
移动时更新链接ask / always / never先从 ask 开始
双链预览按住 Ctrl/⌘ 悬停，或直接悬停预览太吵时可保持「按住修饰键」
保存时格式化CJK 空格、裁剪空白、文件末换行、压缩空行共享 / 要发布的库

专注与打字机也有快捷键（F8 / F9）；打字机还有状态栏入口。沉浸 chrome 与专注都在 更多 → 沉浸编辑。

选项效果
Locale应用 UI：en / zh-CN / 跟随系统
菜单密度紧凑 / 常规 / 宽松
自动隐藏库栏多一点纵向空间
文件树图标Files 里的视觉提示
左右侧栏标签比如大纲贴编辑器、图谱放左边

Images

诚实现状见 图片与附件。在落盘管线完成前，把该分区当成「意图预告」——进度在 路线图。

Graph

箭头、透明度、节点/连线尺寸、动画、力导向参数。布局乱了就恢复默认——关系图谱。

语言（i18n）

应用 UI 语言 ≠ 帮助笔记语言。发布站点用 locales + translationKey 切换——见 欢迎、发布为网站。
