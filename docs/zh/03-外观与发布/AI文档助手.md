# AI 文档助手

**English:** [[AI Document Assistant|English]] · [[设置总览]] · [[库与文件]]

右侧栏的 **AI** 标签是一个面向当前文库的文档助手：你可以提问、附加笔记或文件夹，让它在你明确意图下阅读或改写笔记（写盘可撤销）。

## 第一次使用

1. 打开 **设置 → AI**。
2. 选择 **供应商**（DeepSeek / OpenAI / Anthropic / Google Gemini，或自定义 OpenAI 兼容端点）。
3. 填写该供应商的 **API Key**（各供应商分别保存在本机，互不覆盖）。
4. 在 **模型** 下拉框中选择一个可用模型（自定义端点则手填 Base URL 与模型 ID）。
5. 回到侧栏 AI，输入问题并发送。

未填写密钥时，发送会提示你去设置里补全。

## 供应商与模型

内置供应商的模型来自应用内的目录：选中哪一家，下拉框只显示该家支持的模型。每个模型声明了自己支持的 **思考强度** 档位，以及这些档位如何映射到供应商原生参数——你只需在产品层选择「关闭 / 较低 / 中等 / 较高」，不必记忆各家字段名。

DeepSeek 当前官方模型（见 [模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)）：

| 模型 ID | 说明 |
| --- | --- |
| `deepseek-flash` | DeepSeek-V4.1-Flash，默认推荐；支持非思考 / 思考切换 |
| `deepseek-v4-pro` | DeepSeek-V4-Pro；能力更强、价格更高 |

旧名 `deepseek-v4-flash` 等仍可能被服务端路由到 Flash，但应用目录只提供上述正式 ID。已停用的 `deepseek-chat` / `deepseek-reasoner` 会自动落到 Flash。

| 供应商 | 模型怎么选 | 说明 |
| --- | --- | --- |
| DeepSeek / OpenAI / Anthropic / Gemini | 下拉选择 | 思考强度随模型变化 |
| 自定义（OpenAI 兼容） | 手填 Base URL + 模型 ID | 默认不提供深度思考档位映射 |

Base URL 一般用默认值即可；若你使用代理或区域端点，可在设置里覆盖。

## 思考强度

输入框旁可以切换思考强度（若当前模型只支持一档，该入口会隐藏）。

- **关闭 / 较低**：更快、更省；适合日常改写与问答。
- **中等 / 较高**：更愿意展开推理；回复里可出现可折叠的「思考过程」。

具体有哪些档、以及深度模式下是否仍允许读写工具，由所选模型决定。例如某些旧版推理别名在深度档会关闭工具调用。

## 附件与当前笔记

- 可附加文件或文件夹，作为本轮对话的上下文。
- 若开启「无附件时附带当前笔记」，且你没有显式附加内容，助手会静默带上正在编辑的笔记（不显示芯片）。
- 显式附加优先，并以芯片显示；点击芯片可打开对应笔记。

## 历史与撤销

- 每个文库单独保存对话历史；可新建对话、切换或删除历史。
- 助手写入笔记后，可用「撤销上次写入」恢复改写前的内容。

## 隐私提示

API Key 与供应商偏好保存在本机，不会随设置广播同步。对话内容会发往你所选供应商的接口，请按各家隐私政策使用。
