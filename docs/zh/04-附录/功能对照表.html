功能对照表

English: English · 路线图 · 从Typora与Obsidian迁移

对照目的：降低从 Typora / Obsidian 迁入的预期差。不是功能竞赛榜。

vs Typora

能力TyporaInimark
所见即所得✅✅ 见 编辑模式
源码模式✅✅
打字机 / 专注✅ / ✅✅ / ✅（F9 / F8）
大纲✅✅ 搜索书签与大纲
Pandoc 导出全家桶✅ 强🟡 以 Publish/静态为主
双链知识库❌ 弱✅ 双链与嵌入
关系图谱❌✅ 关系图谱
多库打开文件夹✅ Libraries

操作级差异（Typora → Inimark）

你以前…现在…
靠各种 Pandoc 口味导出用 发布为网站 构建静态站
只开一个文件夹管理多个 库与文件
长期泡在一篇超长文拆想法并用 [[双链]] 串起来

vs Obsidian

能力ObsidianInimark
本地库✅✅ 库与文件
[[wikilinks]]✅✅
Graph✅✅
反向链接✅✅（面板列表）
插件市场✅❌
Canvas✅❌
Daily notes / Templates✅ 核心插件❌
编辑体验源码+实时预览为主Typora 式所见即所得
Publish官方服务 / 第三方✅ 本地 SSG 发布为网站

操作级差异（Obsidian → Inimark）

你以前…现在…
依赖社区插件用内置大纲 / 书签 / 图谱 / 保存时格式化
用 Dataview 查询精选 MOC + 库内搜索
源码旁开预览待在所见即所得；需要时用 Ctrl/⌘+/ 看源码
图片也在文件树里管资源放磁盘；树主要列 Markdown

逐步清单：从Typora与Obsidian迁移。

一句话

  • 来自 Typora：编辑面熟悉，并多出库与图谱。

  • 来自 Obsidian：链接熟悉，并多出更「排版化」的写作面。
