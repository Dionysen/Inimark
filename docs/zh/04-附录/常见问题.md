# 常见问题与排查

**English:** [[FAQ and Troubleshooting|English]] · [[安装与启动]] · [[MOC-中文文档]]

先给短答案，深挖再外链。

## 安装与启动

### macOS 提示应用已损坏 / 无法打开

从 [Releases](https://github.com/Dionysen/Inimark/releases) 重新下载。若 Gatekeeper 拦截未签名构建，打开 **系统设置 → 隐私与安全性** 允许，或第一次右键 → 打开。细节：[[安装与启动]]。

### Windows SmartScreen 警告安装包

在你信任该 GitHub 发布资源时，选 **更多信息 → 仍要运行**。优先用 Latest。

### 怎么改界面语言？

**设置 → 外观 → 语言**：`en`、`zh-CN`，或跟随系统。帮助笔记是另一套双语树 — 改界面语言不会自动切换你正在读的那篇笔记。

## 库与文件

### 我打开了错误的文件夹

在 **设置 → 库** 添加或切换，或再打开另一个文件夹。每个库有自己的 `.inimark/` 会话 — 见 [[库与文件]] 与 [[数据目录]]。

### 为什么文件树里看不到图片？

树列的是 Markdown 笔记。图片被链接时仍可嵌入；在磁盘上管理它们。见 [[图片与附件]]。

### 重命名弄坏了我的双链

检查 **设置 → 编辑器 → 移动时更新链接**（`ask` / `always` / `never`）。选 `never` 时要自己改链接。见 [[双链与嵌入#重命名与改链]]。

## 编辑

### 标记不隐藏 / 整页像源码

你可能在 [[编辑模式#源码模式|源码模式]]。按 `Ctrl/⌘ + /` 回到 WYSIWYG。

### 专注 / 打字机

- **专注**（弱化非活动块）：设置 → Editor、**更多 → 沉浸编辑**，或编辑器聚焦时按 `F8`。
- **打字机**：`F9`、状态栏，或设置 → 编辑器。

### 查找 vs 搜索

| 快捷键 | 范围 |
| --- | --- |
| `Ctrl/⌘ + F` | 当前笔记 |
| `Ctrl/⌘ + Shift + F` | 整座库（文件名 + 内容子串） |

搜索尚无运算符 — 库搜索是不区分大小写的纯子串。

### 正则替换示例（文内）

| 目标 | 模式思路 |
| --- | --- |
| 旧标题前缀 | `^## Draft:` → `## ` |
| 行尾空格 | 能开裁剪保存就用保存时格式化 |
| 简单双链改名残留 | `\[\[Old Name` → `[[New Name`（逐条核对） |

真正重命名笔记时，始终优先用重命名 + 改写流水线。

## 双链与图谱

### 链接是红色 / 虚线且打不开

目标未解析 — 创建笔记（自动补全可帮忙）或改对标题。见 [[双链与嵌入]]。

### 图谱看起来是空的

局部模式只显示 **当前** 笔记的邻居。切到 **库** 模式，或多加一些 `[[链接]]`。先从 MOC 把链接织密。

### 能像 Obsidian 用 `#tags` / 块引用吗？

还不是一等体系 — 见 [[路线图]]。

## 发布

### 预览空白或 CSS 丢失

常见原因是 `baseHref` 不对。根域名 → `/`；GitHub 项目 Pages → `/RepoName/`（本站用 `/Inimark/`）。见 [[发布为网站]]。

### 多语言站点上少了一些笔记

有 `locales` 时，只有落在某语言 `root` 下的笔记会发布。root 之外的会被跳过。

### 有全站搜索吗？

尚未内置。编辑时用桌面搜索标签；全站搜索进度见 [[路线图]]。

## 数据与安全

### 能删 `.inimark/link-index.json` 吗？

可以 — 应用能重建。不要手改当数据库。见 [[数据目录]]。

### `.inimark/` 要不要进 git？

可选。会话 / 最近项偏个人；书签或许值得共享。尽量别把误生成的巨大 `dist/` 提交进去。
