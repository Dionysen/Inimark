# 数据目录

**English:** [[Data Directory|English]] · [[库与文件]] · [[发布为网站]]

## 应用级（大致）

| 存储 | 内容 |
| --- | --- |
| `localStorage` | 应用设置、快捷键、库列表等 |

> 具体 key 以版本为准；不要用手动改存储代替设置 UI。

## 库级：`.inimark/`

每个库根目录下：

| 文件 | 作用 | 删了会怎样 |
| --- | --- | --- |
| `bookmarks.json` | 书签与分组 | 书签丢失 |
| `session.json` | 打开文件、光标/滚动、源码模式、展开目录 | 会话重置 |
| `recent.json` | 最近文件 | 最近记录清空 |
| `link-index.json` | 双链索引缓存 | 应用可重建 |

典型库根布局：

- `*.md` 与资源
- `.inimark/`
  - `bookmarks.json`
  - `session.json`
  - `recent.json`
  - `link-index.json`
- `publish.config.json`
- `dist/`（构建输出）

> [!DANGER]
> `link-index.json` 可被应用重建。**不要**把它当手写数据库长期编辑。

### Git 建议

| 路径 | 建议 |
| --- | --- |
| 笔记 + 资源 | 提交 |
| `publish.config.json` | 提交 |
| `.inimark/bookmarks.json` | 可选（共享枢纽时有用） |
| `.inimark/session.json` / `recent.json` | 通常忽略（偏个人） |
| `link-index.json` | 可选；可重建 |
| `dist/` | 忽略——构建产物 |

## 本帮助库额外文件

| 路径 | 说明 |
| --- | --- |
| `publish.config.json` | Publish 配置（含可选 `locales`） |
| `README.md` | 双语门户首页 |
| `zh/` · `en/` | 平行文档树 |
| `片段/` · `snippets/` | 可嵌入卡片 |
| `dist/` | 构建产物（通常被全局 `dist/` ignore） |
