# 版本历史

**English:** [[Version History|English]] · [[安装与启动]] · [[MOC-中文文档]]

> [!NOTE]
> 下面按版本列出 **更新内容** 与下载入口。安装包始终在对应标签的 GitHub Release 页面；应用内更新读取 **Latest** 发布上的 `latest.json`。
>
> 推送 `vX.Y.Z` 标签时，流水线会读取英文 [[Version History]] 中同版本的 **What’s new**，写入 GitHub Release 描述。若文档中没有该版本，行为与从前一致（使用默认下载说明）。

## 如何下载

1. 打开你想要的版本的 **发布页**（或浏览 [全部 Releases](https://github.com/Dionysen/Inimark/releases)）。
2. 在 **Assets** 里按平台选择安装包：

| 平台 | 常见资源 |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` / `.app.tar.gz`（`aarch64`） |
| macOS（Intel） | `.dmg` / `.app.tar.gz`（`x64`） |
| Windows | `.msi` / `.exe`（NSIS） |
| Linux | `.AppImage` / `.deb` / `.rpm` |

除非在排查旧构建，否则优先用 **Latest**。

## 维护说明（贡献者）

打标签发版前：

1. 在「如何下载」下方、版本列表 **最上方** 增加 `## X.Y.Z — YYYY-MM-DD`。
2. 写上发布页链接与 `### What's new`（英文页）— 该列表会成为 GitHub Release 正文；中文页同步写 `### 更新内容`。
3. 运行 `pnpm bump-version X.Y.Z`，提交，打 `vX.Y.Z` 标签并推送。
