# 版本历史

**English:** [[Version History|English]] · [[安装与启动]] · [[MOC-中文文档]]

> [!NOTE]
> 下面按版本列出 **更新内容** 与下载入口。安装包始终在对应标签的 GitHub Release 页面；应用内更新读取 **Latest** 发布上的 `latest.json`。
>
> 推送 `vX.Y.Z` 标签时，流水线会读取英文 [[Version History]] 中同版本的 **What’s new**，写入 GitHub Release 描述。若文档中没有该版本，行为与从前一致（使用默认下载说明）。

## 如何下载

1. 打开你想要的版本的 **发布页**（或浏览 [全部 Releases](https://github.com/Dionysen/Inimark/releases)）。
2. 在 **Assets** 里按平台选择安装包：

| 平台 | 常见资源 |
| --- | --- |
| macOS（Apple Silicon） | `.dmg` / `.app.tar.gz`（`aarch64`） |
| macOS（Intel） | `.dmg` / `.app.tar.gz`（`x64`） |
| Windows | `.msi` / `.exe`（NSIS） |
| Linux | `.AppImage` / `.deb` / `.rpm` |

除非在排查旧构建，否则优先用 **Latest**。

## 1.0.8 — 2026-09-16

**发布页：** （尚未发版）

### 更新内容

- 修复 Windows 启动时先闪一下「透明 + 原生标题栏」的窗口：启动时保持隐藏，Windows 在显示前去掉边框；macOS 仍在创建时使用 Overlay 装饰，保证红绿灯位置正确；窗口状态不再恢复 decorations / visible
- AI 文档助手（侧栏 Tab，默认右侧，可拖到左侧）：DeepSeek / OpenAI 兼容流式对话、附件上下文、可读写笔记的工具 Agent（写盘可撤销）
- AI 助手改为意图优先：寒暄等无明确任务时先简述当前笔记并询问意图，不主动扫库或回答笔记内嵌问题；有明确意图再调工具
- AI 工具卡片显示友好名称；每轮最终回答左下角可一键复制（不含工具过程），旁侧显示距回答结束的相对时间
- AI 沉浸式输入框：附件等工具在左下、实心发送在右下、无拖拽缩放，高度随内容增至最多 5 行后滚动
- 修复引入 AI 权限后应用 ACL 生效、未显式放行导致设置窗口等 IPC 命令被拒绝的问题

## 1.0.7 — 2026-09-15

**发布页：** [v1.0.7](https://github.com/Dionysen/Inimark/releases/tag/v1.0.7)

### 更新内容

- 去掉文末哨兵空行：普通段落之后不再插入幽灵空段，保存结果与文档一致；仅在代码块 / 表格等无法在其后落笔时补一个段落
- 空白区 / 两侧拖选：仍按鼠标坐标映射选区，滚动改为指针贴边自动滚，不再用 `scrollIntoView` 硬拽视口
- 代码块 / 表格工具栏：拖选扫过时不弹出，仅当光标空闲落入块内时显示
- 修复双链后输入中文标点（如 `。`）时光标跳进引用内部：IME 组字期间不再折叠语法装饰
- 修复侧栏新建 / 复制文件后双链补全找不到新笔记

## 1.0.6 — 2026-09-14

**发布页：** [v1.0.6](https://github.com/Dionysen/Inimark/releases/tag/v1.0.6)

### 更新内容

- 标签：行内 `#tag` / `#parent/child` 芯片，侧栏标签面板（含 YAML front matter），可浏览计数并打开笔记

- 书签与标签列表显示父文件夹路径；查找栏打开时不再被编辑器抢焦点
- 标签样式与主题色微调

## 维护说明（贡献者）

打标签发版前：

1. 在「如何下载」下方、版本列表 **最上方** 增加 `## X.Y.Z — YYYY-MM-DD`。
2. 写上发布页链接与 `### What's new`（英文页）— 该列表会成为 GitHub Release 正文；中文页同步写 `### 更新内容`。
3. 运行 `pnpm bump-version X.Y.Z`，提交，打 `vX.Y.Z` 标签并推送。
