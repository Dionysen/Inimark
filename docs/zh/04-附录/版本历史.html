版本历史

English: English · 安装与启动 · MOC-中文文档

下面按版本列出 更新内容 与下载入口。安装包始终在对应标签的 GitHub Release 页面；应用内更新读取 Latest 发布上的 latest.json。

推送 vX.Y.Z 标签时，流水线会读取英文 Version History 中同版本的 What’s new，写入 GitHub Release 描述。若文档中没有该版本，行为与从前一致（使用默认下载说明）。

如何下载

  1. 打开你想要的版本的 发布页（或浏览 全部 Releases）。

  2. 在 Assets 里按平台选择安装包：

平台常见资源
macOS（Apple Silicon）.dmg / .app.tar.gz（aarch64）
macOS（Intel）.dmg / .app.tar.gz（x64）
Windows.msi / .exe（NSIS）
Linux.AppImage / .deb / .rpm

除非在排查旧构建，否则优先用 Latest。

1.0.6 — 2026-09-14

发布页： v1.0.6

更新内容

  • 标签：行内 #tag / #parent/child 芯片，侧栏标签面板（含 YAML front matter），可浏览计数并打开笔记

  • 外部文件变更检测：打开文件被磁盘修改或删除时横幅提示，冲突时可重载、另存或覆盖

  • 右键菜单「快速插入」当前本地日期时间

  • 代码块缩进大小可配置；编辑器底部始终保留滚动留白，末行可滚到视口中部

  • 关系图谱：悬停高亮、标签随缩放淡入淡出、编辑时保留布局不做整图重排

  • 书签与标签列表显示父文件夹路径；查找栏打开时不再被编辑器抢焦点

  • 标签样式与主题色微调

1.0.5 — 2026-09-12

发布页： v1.0.5

更新内容

  • Publish 营销主页：双语落地页、产品截图与站点顶栏样式

  • 文档站点路径：站点根为首页，帮助笔记落在 /docs 下

  • README 重写（中英）：更强调编辑手感与克制的艺术设计

  • 帮助库新增「版本历史」；打标签发版时可自动把更新说明写入 GitHub Release

1.0.4 — 2026-09-12

发布页： v1.0.4

更新内容

  • 专注模式、首行缩进，以及更丰富的主题 / 代码高亮选项

  • 双链预览触发方式可配置，自动补全行为更清晰

  • Mermaid 与公式块的日常编辑交互更顺手

  • 发布与文档：首页笔记选择、本地化与站点体验打磨

  • 设置搜索、可折叠分组，以及会记住展开状态的侧栏树

1.0.3 — 2026-09-11

发布页： v1.0.3

更新内容

  • Publish / SSG：从本地库生成静态网站

  • 站点页本地图谱；多语言文档结构

  • 帮助库内容与 site-render 能力增强

1.0.2 — 2026-09-10

发布页： v1.0.2

更新内容

  • 应用内自动更新：标题栏胶囊、预检、代理与错误提示

  • 源码模式：Typora 风格的稀疏行号

  • 标题栏菜单与 IME 光标定位打磨

1.0.1 — 2026-09-10

发布页： v1.0.1

更新内容

  • 编辑器内查找与替换

  • 剪贴板 / Markdown 复制改进

  • Callout 上下文菜单、More break、滚动条与链接跳转修复

  • 库拖放目标与管理通知

1.0.0 — 2026-09-06

发布页： v1.0.0

更新内容

  • Inimark 首个公开发布：以编辑体验为先的所见即所得 Markdown、本地库、双链，以及 macOS / Windows / Linux 安装包

维护说明（贡献者）

打标签发版前：

  1. 在「如何下载」下方、版本列表 最上方 增加 ## X.Y.Z — YYYY-MM-DD。

  2. 写上发布页链接与 ### What's new（英文页）— 该列表会成为 GitHub Release 正文；中文页同步写 ### 更新内容。

  3. 运行 pnpm bump-version X.Y.Z，提交，打 vX.Y.Z 标签并推送。
