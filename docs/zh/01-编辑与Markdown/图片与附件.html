图片与附件

English: English · Markdown语法 · 设置总览

图片关系到阅读和发布 — 但存储管线仍在成熟中。这一页把 今天能用的 和 图片设置里预告的 分开说清楚。

把图片放进笔记的方式

1. Markdown 图片语法

![Alt text](assets/diagram.png)
![Alt text](https://example.com/pic.png)

相对路径相对笔记解析（资源放在库内时，发布最稳）。

2. 双链图片嵌入

若文件能被链接索引解析到：

![[photo.png]]

常见类型包括 png、jpeg、gif、webp、svg（以及类似格式）。编辑器会渲染成图片嵌入；笔记则是卡片嵌入 — 见 双链与嵌入。

3. 空图片标记 + 文件选择器

插入空的 ![]() 图片标记时可能弹出文件选择器。今天它可能插入 blob URL 做本地预览 — 本机方便，但 不是 可持久的库路径。若你关心发布或备份，请先把文件拷进库，再用相对路径或 ![[name]] 引用。

图片设置（诚实现状）

设置 → 图片 里能看到：

选项意图
存储模式library-assets 或固定绝对路径文件夹
文件名格式原名 / 时间戳 / 二者兼有
自动创建 assets 目录在库下创建 assets 文件夹
固定目录路径固定模式下的绝对路径

这些选项会 写入设置，但粘贴 / 拖放 → 落盘流水线 尚未完全接通。请勿把「粘贴截图就会进 assets/」当成已完成的工作流。进度见 路线图。

在粘贴落盘落地之前的实用建议：

  1. 在库内保留 assets/（或按笔记分文件夹）。

  2. 用系统 / Finder / 资源管理器把图片放进去。

  3. 用 ![](assets/…) 或 ![[filename.png]] 引用。

文件树显示什么

文件侧栏列出的是 Markdown 笔记（.md / .markdown / .mdown）。图片文件在链接索引能解析时仍可嵌入，但今天还不是树上的一等行。在磁盘上整理资源文件夹，打开笔记来编辑。

发布时的行为

  • 库内的笔记以及页面需要的链接资源会进入静态构建候选。

  • 跳过的目录包括 .git、.obsidian、.inimark、node_modules，以及发布输出目录（通常是 dist）。

  • 优先使用 库内相对路径，这样带 baseHref 部署时图片不易断。

见 发布为网站。

排查

现象可以试试
编辑器里图片不见了检查路径拼写；若文件在库内，试 ![[basename]]
本机正常、站点上坏了baseHref 不对，或文件在库外 / 被排除目录
粘贴没什么用二进制粘贴现状如此 — 请手动保存文件
blob URL 笔记重启前看着好换成库相对路径
