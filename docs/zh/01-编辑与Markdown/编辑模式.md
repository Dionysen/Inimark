# 编辑模式

**English:** [[Editing Modes|English]] · [[MOC-中文文档]]

Inimark 的编辑哲学很简单：

> **一张表面，两种深度** —— 默认像读排好版的文章；需要时再露出 Markdown 源码。

## 所见即所得

默认模式（Typora 风格）：

- 光标所在行 / 片段会显示语法标记（`**`、`#`、`[[`…）
- 光标离开后，标记隐藏，只剩排版结果
- **没有**左右分屏「实时预览」——预览就是编辑面本身

> [!TIP]
> 若你从「左 MD 右 HTML」编辑器迁来，先花一天只待在所见即所得；多数人会更快进入心流。对照见 [[功能对照表]]。

### 什么时候最适合所见即所得

- 起草正文、大纲、会议纪要
- 边读自己的文字边轻量排版
- 点开双链又不想离开排版视图

### 粘贴行为

- 普通粘贴可能带上剪贴板里的富文本。
- **纯文本粘贴**（`Ctrl/⌘ + Shift + V`）更适合代码和命令行日志，缩进不容易乱。

## 源码模式

快捷键：`Ctrl + /`（macOS：`⌘ + /`）

| 特性 | 说明 |
| --- | --- |
| 引擎 | CodeMirror |
| 行号 | 支持 |
| 适合 | 大段结构调整、乱七八糟的粘贴、排查语法 |

切回所见即所得后，文档会重新折叠成排版视图。

### 什么时候该切到源码

| 场景 | 为什么源码更省事 |
| --- | --- |
| 大块 Mermaid / KaTeX | 直接改围栏，少被控件打扰 |
| 粘贴后表格坏了 | 管道符和行列一目了然 |
| Front matter / HTML 注释 | 字符级精确控制 |
| 格式「怪怪的」 | 好找漏网的标记 |

## 打字机模式

让 **当前行靠近垂直居中**，少上下扫视——适合长文。

- 在 **设置 → Editor** 开启
- 也可用 **`F9`** 或 **状态栏** 切换（见 [[界面导览]]）

从 Editor 分区改动的状态会写入设置。

## 专注模式

淡化光标以外的块，让当前段落更突出。

- 编辑器聚焦时按 **`F8`** 切换
- 目前是会话级开关（设置里没有单独勾选项）

可与自动隐藏标题栏 / 状态栏一起用，更接近「一张纸」——见 [[主题与外观]]。

## 模式对照

| 模式 | 成熟度 | 入口 |
| --- | --- | --- |
| 所见即所得 | ✅ | 默认 |
| 源码 | ✅ | `Ctrl/⌘+/` |
| 打字机 | ✅ | `F9` / 设置 / 状态栏 |
| 专注 | ✅ | `F8` |
