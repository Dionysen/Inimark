## 标题

```markdown
# H1
## H2
### H3
#### H4
##### H5
###### H6
```

用快捷键：`Ctrl/⌘ + 1…6`，段落用 `Ctrl/⌘ + 0`（详见 [[查找替换与快捷键]]）。

## 行内样式

| 效果 | 写法 |
| --- | --- |
| **加粗** | `**加粗**` |
| *斜体* | `*斜体*` |
| ***粗斜体*** | `***粗斜体***` |
| ~~删除线~~ | `~~删除线~~` |
| ==高亮== | `==高亮==` |
| <u>下划线</u> | `<u>下划线</u>` |
| `行内代码` | `` `行内代码` `` |
| H~2~O | `H~2~O` |
| E=mc^2^ | `E=mc^2^` |

转义：在标记前加 `\`，例如 `\*\*不是加粗\*\*`。

## 引用与 Callout 提示块

普通引用：

> 「未经审视的生活不值得过。」—— 常被知识管理文章引用的一句。

### Callout

> [!NOTE]
> 中性说明：补充上下文，不打断主线。

> [!TIP]
> 小技巧：`Ctrl/⌘ + K` 插入 Markdown 链接；双链请直接输入 `[[`。

> [!IMPORTANT]
> 关键：重命名文件时注意 [[双链与嵌入#重命名与改链|改链策略]]。

> [!WARNING]
> 警告：图片「粘贴落盘」相关设置可能尚未完全接线，见 [[路线图]]。

> [!DANGER]
> 危险：不要把手动改坏 `.inimark/link-index.json` 当成日常操作。

别名：`WARN` / `CAUTION` 会归到 warning 一类。

## Front matter

本页顶部的 YAML：

```yaml
---

---
```

可用于标题等元数据；发布站点时会读取 `title`，多语言还会读 `lang` / `translationKey`（见 [[发布为网站]]）。

## TOC · 目录

编辑器支持在正文中插入目录标记（单独一行），按标题生成文内目录。本帮助库改用侧栏 Outline，因此这些文档里不再放置该标记。

## HTML 与注释

- HTML 块：编辑器可容纳（请克制使用）
- 注释：`<!-- 这行在源码里，阅读时可折叠认知负担 -->`
- 摘要分割：发布/摘要场景可用编辑器的 more 分割注释（本帮助库不使用）

## Emoji
