# 数学公式与图表


**English:** [[Math and Diagrams|English]] · [[Markdown语法]] · [[MOC-中文文档]]

Inimark 内置 **KaTeX** 与 **Mermaid**，写法与常见学术 / 技术笔记一致。

## 行内公式

爱因斯坦质能关系：$E = mc^2$

勾股定理：$a^2 + b^2 = c^2$

写法：

```markdown
$E = mc^2$
```

## 块级公式

贝叶斯定理：

$$
P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}
$$

矩阵示例：

$$
\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}
\begin{pmatrix}
x \\
y
\end{pmatrix}
=
\begin{pmatrix}
ax + by \\
cx + dy
\end{pmatrix}
$$
