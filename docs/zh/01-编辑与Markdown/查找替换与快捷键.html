查找替换与快捷键

English: English · 编辑模式 · 设置总览

查找与替换（当前笔记）

操作Windows / LinuxmacOS
查找Ctrl + F⌘ + F
替换Ctrl + H⌘ + H

查找栏支持：

  • 区分大小写

  • 全词匹配

  • 正则表达式

  • 上一个 / 下一个

  • 替换 / 全部替换

跨文件搜索在侧栏 Search（Ctrl/⌘ + Shift + F）——见 搜索书签与大纲。Ctrl+F 只作用于 当前文档。

文档内正则思路（仅当前笔记）

目标示例模式替换为
去掉草稿标题前缀^## Draft:\s*##
统一某个标签TODO:Next:
小心改残留双链\[\[旧标题[[新标题

请逐条确认。真正的文件改名，请用文件树重命名 + 改链策略，而不是正则硬扫。

三种搜索范围

范围入口匹配什么
当前笔记Ctrl/⌘ + F打开文件内的文本 / 正则
整个库Ctrl/⌘ + Shift + F文件名与内容的子串（不区分大小写，暂无运算符）
快速打开常为 Ctrl/⌘ + O模糊 文件名 + 最近打开

Inimark 里的「打开」常常是 快速打开（模糊找笔记），不是系统文件对话框。见 库与文件。

字体缩放

Ctrl/⌘ + 滚轮 可缩放编辑区字体——长文阅读很有用。
