# 查找替换与快捷键

**English:** [[Find Replace and Shortcuts|English]] · [[编辑模式]] · [[设置总览]]

## 查找与替换（当前笔记）

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 查找 | `Ctrl + F` | `⌘ + F` |
| 替换 | `Ctrl + H` | `⌘ + H` |

查找栏支持：

- [x] 区分大小写
- [x] 全词匹配
- [x] 正则表达式
- [x] 上一个 / 下一个
- [x] 替换 / 全部替换

> [!TIP]
> 跨文件搜索在侧栏 **Search**（`Ctrl/⌘ + Shift + F`）——见 [[搜索书签与大纲]]。`Ctrl+F` 只作用于 **当前文档**。

### 文档内正则思路（仅当前笔记）

| 目标 | 示例模式 | 替换为 |
| --- | --- | --- |
| 去掉草稿标题前缀 | `^## Draft:\s*` | `## ` |
| 统一某个标签 | `TODO:` | `Next:` |
| 小心改残留双链 | `\[\[旧标题` | `[[新标题` |

请逐条确认。真正的文件改名，请用文件树重命名 + 改链策略，而不是正则硬扫。

## 三种搜索范围

| 范围 | 入口 | 匹配什么 |
| --- | --- | --- |
| 当前笔记 | `Ctrl/⌘ + F` | 打开文件内的文本 / 正则 |
| 整个库 | `Ctrl/⌘ + Shift + F` | 文件名与内容的子串（不区分大小写，暂无运算符） |
| 快速打开 | 常为 `Ctrl/⌘ + O` | 模糊 **文件名** + 最近打开 |

### 块级插入（`Alt` 组合）

| 动作 | Windows / Linux | macOS |
| --- | --- | --- |
| 无序列表 | `Alt + Ctrl + U` | `Alt + ⌘ + U` |
| 有序列表 | `Alt + Ctrl + O` | `Alt + ⌘ + O` |
| 任务列表 | `Alt + Ctrl + X` | `Alt + ⌘ + X` |
| 引用 | `Alt + Ctrl + Q` | `Alt + ⌘ + Q` |
| 代码块 | `Alt + Ctrl + C` | `Alt + ⌘ + C` |
| 公式块 | `Alt + Ctrl + B` | `Alt + ⌘ + B` |
| 脚注标记 | `Alt + Ctrl + R` | `Alt + ⌘ + R` |
| 分割线 | `Alt + Ctrl + -` | `Alt + ⌘ + -` |

表格行列移动：`Alt + Ctrl/⌘ + 方向键`（平台略有差异）。若在设置里重绑过，以 **设置 → Shortcuts** 为准。

## 应用级快捷键（可重绑）

**设置 → Shortcuts** 中的默认值：

| 动作 | 默认（macOS 上 Ctrl 显示为 ⌘） |
| --- | --- |
| 保存 | `Ctrl + S` |
| 另存为 | `Ctrl + Shift + S` |
| 新建文件 | `Ctrl + N` |
| 快速打开 / 打开 | `Ctrl + O` |
| 打开文件夹 | `Ctrl + Shift + O` |
| 关闭 | `Ctrl + W` |
| 切换侧栏 | `Ctrl + B` |
| 库内搜索 | `Ctrl + Shift + F` |
| 打开设置 | `Ctrl + ,` |
| 树中重命名 | `F2` |
| 树中删除 | `Delete` |
| 树中剪切 / 复制 / 粘贴 | `Ctrl + X` / `C` / `V`（文件树聚焦时） |

> [!NOTE]
> Inimark 里的「打开」常常是 **快速打开**（模糊找笔记），不是系统文件对话框。见 [[库与文件]]。

## 字体缩放

`Ctrl/⌘ + 滚轮` 可缩放编辑区字体——长文阅读很有用。

## 键位心智模型

- **当前文档** — `Ctrl/⌘+F` 查找 · `B` / `I` / `K` 格式
- **当前库** — 快速打开 · 侧栏 Search
- **应用** — 设置 · 切换侧栏
