代码与语法高亮

English: English · Markdown语法 · 数学公式与图表

技术笔记好不好读，常常取决于代码是否清楚。Inimark 支持 行内代码、围栏代码块，以及由 CodeMirror 语言包驱动的 语法高亮（配色来自 主题与外观）。

在 Inimark 里打开本页，即可直接看到高亮效果。若语言标签不被识别，仍会显示等宽代码块，只是没有着色。发布站点也会在构建时用同一套语言包生成高亮（无需浏览器再跑一遍高亮脚本）。

行内代码

用反引号包住短片段：

C++ 里常用 `std::vector`，Rust 里常见 `Path`。

渲染效果：C++ 里常用 std::vector，Rust 里常见 Path。

行内代码快捷键：Ctrl/⌘ + Shift + `（见 查找替换与快捷键）。

适合：API 名、文件名、命令行参数、不宜做成整块的短标记。

围栏代码块

怎么插入

  1. 快捷键：Alt + Ctrl/⌘ + C 插入代码块。

  2. 或在 源码模式 里手写围栏：

```python
print("hello")
```

  1. 在起始围栏写上 语言标签（python、cpp、rust…），用来选择高亮。

从浏览器粘贴容易带上乱七八糟的格式时，用 纯文本粘贴（Ctrl/⌘ + Shift + V），缩进更稳。

按语言展示

下面每段都是可复制的短示例。

C++

#include <iostream>
#include <vector>

int main() {
  std::vector<int> xs{1, 2, 3};
  for (int x : xs) {
    std::cout << x << '\n';
  }
  return 0;
}

Python

from dataclasses import dataclass

@dataclass
class Point:
    x: float
    y: float

def length(p: Point) -> float:
    return (p.x ** 2 + p.y ** 2) ** 0.5

print(length(Point(3, 4)))

Java

import java.util.List;

public final class Greeter {
  public static String join(List<String> parts) {
    return String.join(" · ", parts);
  }

  public static void main(String[] args) {
    System.out.println(join(List.of("Inimark", "Java")));
  }
}

Rust

fn factorial(n: u64) -> u64 {
    (1..=n).product()
}

fn main() {
    let n = 6;
    println!("{n}! = {}", factorial(n));
}

R

mean_sd <- function(x) {
  c(mean = mean(x), sd = sd(x))
}

xs <- c(1.2, 3.4, 5.6, 7.8)
print(mean_sd(xs))

Swift

struct User {
  let id: Int
  var name: String
}

func greet(_ user: User) -> String {
  "Hello, \(user.name) (#\(user.id))"
}

let alice = User(id: 1, name: "Alice")
print(greet(alice))

TypeScript

type Note = { path: string; title: string };

export function displayTitle(note: Note): string {
  return note.title.trim() || note.path;
}

Go

package main

import "fmt"

func sum(xs []int) int {
  total := 0
  for _, x := range xs {
    total += x
  }
  return total
}

func main() {
  fmt.Println(sum([]int{1, 2, 3}))
}
